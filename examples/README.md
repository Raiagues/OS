# Course activities

Open an activity's README for its implementation, diagrams, commands and output.
Each folder builds from its own source files.

| Order | Activity | Entry point |
| --- | --- | --- |
| 1 | [Pixels and characters](01-pixels/README.md) | [main.c](01-pixels/src/main.c) |
| 2 | [Console](02-console/README.md) | [main.c](02-console/src/main.c) |
| 3 | [Scrolling](03-scroll/README.md) | [main.c](03-scroll/src/main.c) |
| 4 | [UART](04-uart/README.md) | [main.c](04-uart/src/main.c) |
| 5 | [Timer interrupts](05-clock/README.md) | [main.c](05-clock/src/main.c) |
| 6 | [Processes](06-processes/README.md) | [main.c](06-processes/src/main.c) |

The first four activities draw or transmit text. Activity 5 adds timer
interrupts. Activity 6 combines those mechanisms with a process table and
assembly context switching.

See the [root README](../README.md) for the course environment and credits.
